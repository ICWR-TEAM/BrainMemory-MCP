# BrainMemory-MCP Changelog — 2026-08-20

## Release v0.11.1

### Added
- Added optional HTTP/SSE Bearer authorization with `--key <secret>`.
- Added `BRAINMEMORY_KEY` as the environment-variable alternative, recommended to avoid exposing a key in shell history.
- Added constant-time key comparison and `401 Unauthorized` responses with `WWW-Authenticate: Bearer` for missing or invalid credentials.
- Added authorization tests covering optional configuration, environment configuration, rejected credentials, and accepted credentials.

### Changed
- Both the `/sse` stream and `/messages/` POST endpoint are protected whenever a key is configured.
- Web mode remains unauthenticated when no key is configured for backward compatibility.
- Updated README web-mode configuration, security guidance, and client header example.
- Bumped package version from `0.11.0` to `0.11.1`.

### Security
- Bearer authorization should be used behind HTTPS when exposed over a network because plain HTTP does not encrypt the key.
