# BrainMemory-MCP Changelog — 2026-08-19

## Release v0.10.2

### Changed
- `export_graph_html` now requires a `directory` parameter so agents must direct graph exports into their own workspace/output directory instead of the daemon working directory.
- Bumped package version from `0.10.1` to `0.10.2`.

## Release v0.10.0

### Added
- **`export_graph_html` tool**: Renders full knowledge graph into a 3D interactive standalone HTML visualization (`three.js` + `3d-force-graph` HUD theme) embedded with graph JSON data.
  - Page title updated to `BrainMemory MCP — 3D Knowledge Graph`.
  - Added byline credit `By HarshXor - R&D incrustwerush.org`.
- **`restore_memories` tool**: Soft-delete safety net for memories with trash retention (`memory_trash` table), versioning snapshots (`memory_history` table), history lookup, version rollback, and trash purging.
- **`transfer_memories` tool**: Portable graph export/import and instant online database backups (`backup_now()`).
- Updated package data configuration in `pyproject.toml` (`[tool.setuptools.package-data]`) to bundle `templates/*.html`.

### Changed
- Expanded total MCP tool count from 12 to 15 tools.
- `forget_memories()` now performs a soft delete by snapshotting memories, details, and connections into `memory_trash` before purging live records.
- `update_memories()` automatically creates revision snapshots in `memory_history` before mutating record fields.
- Bumped package version from `0.9.0` to `0.10.0`.
## v0.10.3

- `export_graph_html.directory` must now be an absolute path; relative values such as `.` or `./` are rejected so agents must explicitly pass their workspace path.
