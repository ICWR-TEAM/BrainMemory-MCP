## MVP — implemented the BrainMemory-MCP server
- Added Python package under `src/brainmemory_mcp/` (src layout):
  - `memory.py` — SQLite-backed `MemoryStore` + `Memory` model. Persists to
    `~/.brainmemory-mcp/memory.db` (WAL). Location overridable via
    `--data-dir` / `$BRAINMEMORY_HOME`. CRUD + search (text/category/tag/
    importance) + summary stats; safe input handling, no silent data loss.
  - `server.py` — `FastMCP` server exposing 7 Cognitive tools
    (`store_memory`, `recall_memory`, `search_memory`, `list_memories`,
    `update_memory`, `forget_memory`, `summarize_memories`) and a
    `brainmemory://stats` resource. Runs over the SSE transport.
  - `__main__.py` — CLI entry point (`--host`, `--port`, `--data-dir`,
    `--version`) with env-var fallbacks.
  - `__init__.py` — package exports + version.
- Packaging: added `pyproject.toml` (setuptools) making the project installable
  via `python3 -m pip install .`; provides console script `brainmemory-mcp`
  and `python3 -m brainmemory_mcp`. Runtime deps: `mcp`, `starlette`, `uvicorn`.
- Docs: added `README.md` (install/run/connect) and `.gitignore` (ignores the
  local `.brainmemory-mcp/` data and SQLite files).
- Verified locally (Python 3.13 venv):
  - `pip install .` builds a wheel and installs successfully.
  - `MemoryStore` store/search/update/forget/stats smoke test passes.
  - Server boots over SSE; `GET /sse` returns the MCP `event: endpoint`
    handshake; message endpoint at `/messages/`.

## Architecture decisions logged (see NOTE.md)
- Use official `mcp` SDK `FastMCP` with `transport="sse"`.
- Persist memory in local SQLite at `~/.brainmemory-mcp/memory.db`.
- Adopt `src/` layout + `pyproject.toml` with a `brainmemory-mcp` console script.
